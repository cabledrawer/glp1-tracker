# Dose & Weight

Simple iPhone app (SwiftUI, iOS 17+): log weight, log weekly GLP-1 doses, see both on one chart,
get a weekly injection-day reminder. All data stays on the phone.

The Xcode project is generated from `project.yml` by XcodeGen. GitHub Actions builds an unsigned
`.ipa` on every push to `main` (Actions tab > latest run > Artifacts); sideload it with AltStore.
